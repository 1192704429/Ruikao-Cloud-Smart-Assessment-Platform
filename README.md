# 基于Spring Boot 3.2与Vue的智慧测评管理平台的设计与实现

> 本文围绕高校教务管理与在线考试场景，基于Spring Boot 3.2、Vue与MySQL技术栈，设计并实现了一套面向管理员、教师与学生三类角色的智慧测评管理平台，涵盖题库管理、智能组卷、在线考试、AI评阅与成绩统计等核心功能。

## 一、项目背景

- 传统考试管理流程中存在组卷效率低、题库分散、人工阅卷耗时长、成绩统计滞后等问题，难以满足高校日常教学测评需求。

- 教务管理人员需要统一管理教师、学生、课程、班级及考试审核信息，当前缺乏一体化管理工具支撑。

- 教师缺乏便捷的题库建设、知识库沉淀与智能组卷手段，出题及阅卷工作量大、主观题评分一致性难以保证。

- 学生考试体验单一，无法及时查看考试安排、在线作答及课程成绩分析，学习反馈不够直观。

- 本项目围绕上述问题，构建覆盖考务管理、考试组织、AI辅助出题评阅与成绩分析的一体化智慧测评管理平台。

## 二、功能模块介绍

- 本系统划分为管理员端（教务处）、教师端、学生端三个子系统。

- 各子系统面向不同角色提供差异化的功能服务，具体角色与所属端的对应关系如下表所示。

| 所属端 | 角色 | 核心职能 |
| --- | --- | --- |
| 管理员端 | 管理员（教务处） | 基础数据管理、考试审核与平台监管 |
| 教师端 | 教师 | 题库建设、试卷与考试管理、AI组卷出题、成绩分析 |
| 学生端 | 学生 | 在线考试、成绩查询与课程学习统计 |

## 五、主要业务流程

1. 管理员登录系统后，通过教师管理、学生管理、班级管理与课程管理模块完成基础数据配置。

2. 教师在题库管理模块录入试题，并可上传教学文档至知识库管理模块进行解析。

3. 教师通过AI出题功能辅助生成试题，并利用AI智能组卷按知识点与难度自动生成试卷。

4. 教师创建考试，设置考试时间与参考班级，并提交至管理员端进行考试审核。

5. 管理员在考试审核模块对考试安排进行审核，确认无误后发布考试。

6. 学生登录系统首页查看已发布的考试任务，进入我的考试模块确认考试信息。

7. 学生在考试时间内进入在线考试模块作答，完成主观题与客观题后提交试卷。

8. 系统对客观题自动评分，AI对主观题进行智能辅助评分，生成考试成绩。

9. 教师在成绩统计模块查看考试成绩数据与可视化分析结果，并可将成绩反馈至学生端。

10. 学生在成绩查看与课程统计模块查看个人成绩与课程学习分析报告。

## 六、项目拓展性

- 支持接入更丰富的AI模型服务，实现主观题深度评阅、学习行为分析与个性化学习路径推荐。

- 可扩展题库共享协作机制，支持多教师共建题库与校际资源共享。

- 引入考试防作弊监测模块，支持人脸识别、切屏检测与异常行为告警。

- 可扩展消息通知服务，通过邮件、短信或微信方式向师生推送考试安排与成绩通知。

- 预留数据开放接口，可对接学校教务系统、统一身份认证平台及第三方学习平台，实现数据互通。

- 支持部署至云端容器化环境，结合分布式缓存与文件存储提升高并发考试场景下的系统稳定性。
